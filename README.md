# Project Archive Wiki

Project Archive 的非官方静态资料站，集中展示公告、学生图鉴、战斗资料与宣传片。

当前工作区版本：**0.4.1 Beta** · 更新日期：**2026-09-13** · 状态：**待发布**。

本版重点：游戏风格完整资料面板、古书馆技能图标、原图金色星级，以及 Reisa 嘴部与优香（睡衣）玩具显示修复。可直接复制的 [GitHub 更新简报](docs/releases/0.4.1-beta.md) 已单独整理；上一版提交为 [0.4.0 beta](https://github.com/pan0001/paweb/commit/f5160a5de7ba76e787f6b9f8b4bb151f9601861c)。

网站无需构建，可部署到静态网站服务。主布局、详情弹窗与角色选择屏分别由 `styles.css`、`styles/details.css`、`styles/gallery.css` 管理；`styles/dossier.css` 与 `scripts/dossier.js` 为学生完整资料提供游戏风格的页签面板。`styles/game-ui.css`、`styles/site-ui.css` 与 `styles/button-art.css` 保留原皮肤和控件基础，`styles/atlas-frames.css`、`styles/atlas-ui.css` 使用作者提供的 Common / Combat 图集统一控件视觉。`styles/site-backgrounds.css` 管理首页以外的国服官网参考背景，最后加载的 `styles/site-motion.css` 提供背景动效与角色切换基础样式。直接打开 `index.html` 可查看立绘与资料；3D / Spine 动态预览需要通过本地 HTTP 服务打开。Blueaka 字体在线加载，无法联网时回退到 Noto Sans / 系统字体；YouTube 视频与外部图鉴链接仍需要网络。

## 功能

- 37 名学生资料与 111 条技能记录；技能、角色说明与使用备注支持 CN / EN / JP
- 上方横向学院卡片、中央角色展示与底部学生长条；支持 12 个学院与战斗定位筛选
- 角色名、学院、武器、站位及战斗定位搜索
- 游戏风格学生详情弹窗：基本信息、技能档案、使用备注三页签，以及对应 Kivo Wiki 图鉴入口
- 111 个技能位置使用本地古书馆图标，改编／组合技能明确标注参考；原图金色星星展示真实星级
- 立绘、3D 模型与 Spine 记忆大厅按需切换；胜利出场、循环展示、点击 Pick Up 互动与顺滑动作过渡
- 学院徽记、选人分层入场与切换过场；记忆大厅支持填充／完整画面、双相纸交换和全屏预览
- 带独立地址的公告详情，例如 `#announcement/izuna-update`
- 中文、English、日本語即时切换
- 可记忆的日间与夜间模式
- 四支 Project Archive 宣传片站内切换播放
- 响应式桌面与移动端布局
- 键盘操作、焦点管理及“减少动态效果”支持

## 本地运行

只看立绘与资料，可以直接打开 `index.html`。**查看 3D 模型或记忆大厅时，请通过 HTTP 预览打开，不能继续使用 `file://` 地址。** 浏览器的模块加载有本地文件限制，参考 [MDN 模块运行说明](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules#troubleshooting)。

Windows 推荐在项目文件夹双击 `start-preview.cmd`，保持启动窗口开启，然后打开：

```text
http://127.0.0.1:18900/index.html#characters
```

启动器优先使用 PATH 中的 Node.js，找不到时尝试已有的 Codex 随附运行时；不会安装软件。其他系统可使用 Node.js 18 或更新版本运行 `node scripts/serve-preview.mjs`。服务仅供本机访问，按 Ctrl+C 即可停止。如端口已被其他程序占用，可通过 `PAWEB_PREVIEW_PORT` 指定其他端口，再使用终端显示的地址；页面内置快捷入口使用默认端口 18900。

或者在已安装 Python 的环境中运行：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8000
```

如果播放器仍受地区、年龄或浏览器策略限制，可以使用页面中的“在 YouTube 观看”按钮。

## 内容维护

主要内容都位于 `index.html` 底部的 JavaScript 数据区：

- `translations`：CN / EN / JP 界面文案
- `localizedValues`：学院、战斗定位、武器及战斗类型译名
- `i18n/characters.en.js`、`i18n/characters.jp.js`：按学生 ID 维护的角色说明与使用备注
- `i18n/skills.en.js`、`i18n/skills.jp.js`：按“学生 ID:技能序号”维护的技能名称与说明
- `characterNames`：角色名称与特殊形态译名
- `announcements`：公告标题、摘要与完整正文
- `trailers`：YouTube 影片 ID、链接与多语言标题
- `characters`：学生数值、技能、备注、图片路径及 Kivo 图鉴 ID
- `verifiedStudentFacts`：按 Kivo 图鉴复核的学院、初始星级、战斗定位、站位、武器与攻防类型

技能图标独立维护于 `scripts/skill-icon-map.json` 与 `assets/ui/skill-icons/`，不从图标来源覆盖本站技能数值。更新来源快照后需人工核对角色装束、形态和派生技能，再生成本地索引；流程、对应规则及素材说明见 [技能图标说明](assets/ui/skill-icons/README.md)。离线映射与原图校验运行 `node scripts/check-skill-icons.cjs`，HTTP 加载校验运行 `node scripts/check-preview.mjs`。

样式按职责维护：

- `styles.css`：字体、全站颜色、导航与首屏、公告与宣传片、筛选工具、学生卡片、明暗主题、响应式布局及动效
- `styles/details.css`：学生与公告详情弹窗、学院主题色、战斗定位与攻击／防御等语义标签
- `styles/rarity.css`：原图金色星级、灰色未获得星位与高对比回退；数量来自原有角色数据，图集坐标和哈希与 `assets/ui/reference-atlas/frames.json` 同步维护
- `styles/dossier.css` + `scripts/dossier.js`：仅增强学生完整资料。样式在 `site-motion.css` 之前加载，脚本在 `renderCharacterModal` 生成本地化数据后挂载；原 `.basic-section`、`.stats-section`、`.skills-section`、`.description-section` 与 `.notes-section` 保留，字段仍在 `index.html` 和 `i18n` 文件维护。按钮只展开或跳转已有资料，不执行升级操作。使用 `PAWEB_TEST_MODULES` 指向含 jsdom 的开发依赖目录后运行 `node scripts/check-ui.cjs` 做三语回归
- `styles/gallery.css`：横向学院卡片、中央角色展示、底部学生长条及移动端排列
- `styles/lobby.css`：仅限记忆大厅的叠纸相框、图集图钉、填充／完整画面控件和全屏／窄屏适配；不要给 3D 展示区域套相框
- `styles/game-ui.css`：游戏参考卡片、深蓝斜切资料栏、攻防状态块及其日夜／移动端适配
- `styles/site-ui.css`：全站游戏纸面皮肤；导航、首屏、公告、宣传片、角色区衔接、详情与页脚，在原布局和局部皮肤之后加载
- `styles/button-art.css`：生成按钮素材的显示、方向与控件状态；素材与完整提示词在 `assets/ui/generated-buttons/`，不将多语言文字烘焙进图片
- `styles/atlas-frames.css`、`styles/atlas-ui.css`：当前图集引用坐标与全站皮肤，在上述文件后加载；修改坐标时同步更新 `assets/ui/reference-atlas/frames.json`，运行 `node scripts/check-atlas-ui.cjs` 核对
- `styles/site-backgrounds.css`：覆盖公告、宣传片、选人与关于区的背景及舞台装饰；使用 `assets/ui/archive-triangles.svg` 透明度遮罩，日夜颜色由 CSS 提供，手机端缩小纹理。不要在该文件修改首页、控件布局或模型样式
- `styles/site-motion.css`：最后加载，控制装饰层漂移／呼吸、静止回退、页脚暂停按钮和控件反馈。`scripts/gallery.js` 在媒体就绪后用 Web Animations 完成角色淡入／淡出，并负责取消过期过渡；无该 API 或系统减少动态效果时直接切换。动效回归使用 `PAWEB_TEST_MODULES` 指定 jsdom 后运行 `node scripts/check-gallery-motion.cjs`
- `scripts/ui-motion.js`：独立管理有限时长的交互动效；`setSelectedControl` 仅在选中状态改变时触发内层回弹，列表重绘后调用 `observeCards` 注册公告／宣传片入场。只动画装饰层或内层元素，不接管按钮动作、画布手势和键盘导航。运行 `node scripts/check-interface-motion.cjs` 检查连点、取消、聚焦及降级逻辑；仍需浏览器复核观感
- `assets/ui/reference-atlas/preview.html`：通过本地服务打开的图标／纹理检查页；原 PNG 保留不变，网页文字与状态不写入图片。相对图集 URL 在使用它的 CSS 文件中解析，新增引用样式也应放在 `styles/` 内
- `scripts/gallery.js`：角色选择、Q / E 快捷键、展示模式与加载状态；不在语言切换时重新加载当前模型。`academyEmblem()` 统一学院卡片与角色背景的本地图片映射；`gallery.update(list, language, academyFilter)` 仅在学院筛选改变时触发大过场，徽记始终取自当前学生。徽记／扫光使用独立的有限时长动画队列，不与媒体出场和加载互相取消；运行 `node scripts/check-academy-transition.cjs` 检查
- `scripts/model-viewer.js`：3D 加载、稳定站姿取景、胜利出场／循环与点击拾起；动画下拉框为手动循环覆盖，点击互动恢复自动胜利循环。Spine 使用独立播放器，不套用模型动作序列
- `scripts/toon-renderer.js`：卡通明暗与细描边；描边使用当前材质原图 RGB／原 UV 取色，`OUTLINE_PROFILES` 只控制线宽、透明度、压暗和饱和度，不再指定固定色相。不要恢复所有角色统一紫色或将游戏 alpha 当作描边透明度
- `scripts/ba-model-materials.js`：模型 Toon 材质、透明附件例外、眼嘴三角形分区、默认嘴部图集 UV 与光环头部绑定；不要把游戏 alpha 数据重新统一当成透明度
- `isolateInvalidSkinning`：仅在一个网格的所有顶点权重均无效时将其从预览绘制中隔离，保留原始几何和骨骼；`getModelBounds` 忽略隐藏网格和非有限变换顶点。不要用任意骨骼或统一权重冒充丢失的绑定信息

媒体索引位于 `assets/media/catalog.json`，页面通过同内容的 `catalog.js` 读取。原文件约 773 MiB，请在公开推送前评估静态托管容量与 Git 大文件策略。本次下载中的 HEAD 请求曾有 6 次失败，但随后 GET 已获取全部 477 个文件；不要只按诊断记录的数量判断文件是否缺失。`scripts/sync-student-media.mjs` 可根据来源重新核对并下载，已校验的文件会跳过。Spine 集成基于项目作者已确认的许可证，运行库许可保留在 `assets/vendor/`，素材授权与运行库许可分别维护。

学院卡片由 `index.html` 中的 `renderAcademyCards()` 生成，学院与学生的归属沿用 `characters` 数据；卡片人数仅代表本站已收录学生，不代表游戏内学院总人数。校徽位于 `assets/ui/academies/`，可用 `node scripts/sync-academy-logos.mjs` 重新获取公开资源及来源索引。

模型回归：`node scripts/check-preview.mjs` 检查 HTTP 与加载链；`node scripts/check-model-materials.mjs` 使用开发依赖 `sharp` 解码真实贴图、检查材质与嘴部骨骼，`PAWEB_IMAGE_MODULES` 可指定已有 `node_modules` 目录；`node scripts/check-model-halos.mjs` 检查光环变换；`node scripts/check-model-animation.mjs` 检查真实模型动作序列和合成手势事件。上述检查均不启动浏览器，不能代替 WebGL 实际画面与触摸设备检查。

调整视觉时同步检查 CN / EN / JP 文案、日间／夜间主题和移动端长列表；动效需保留 `prefers-reduced-motion` 适配。图片来源与备用状态见 `assets/ui/README.md`。

语言和主题偏好保存在浏览器本地存储中，键名分别为 `pa-language` 与 `pa-theme`。

版本维护：下次更新同步修改 README 顶部版本／日期、更新记录和 `docs/releases/` 简报。只有完成实际发布后才移除“待发布”，并补充真实发布或提交链接；不要批量改写历史版本号，也不要将 Three.js、Spine 或媒体索引的版本号当作网站版本修改。
