# 0.4.1 Beta — 学生资料与技能图标更新

本次更新在保留原有选人布局与战斗数据的基础上，重点完善学生完整资料的游戏风格 UI，并修复部分角色模型的显示问题。

## 界面与图标

- 重做「查看完整资料」：新增基本信息、技能档案、使用备注三页签，采用深蓝页签、斜切技能卡和青蓝按钮，支持查看属性详情、技能效果与武器资料。
- 核对 37 名角色对应装束的古书馆资料，为全部 111 个技能位置接入图标；107 张原始 PNG 已本地保存，展示时无需向古书馆请求图片。
- 89 项按名称或译名对应，3 项组合被动与 19 项改编技能明确标为参考；图标对应不代表原作技能与本站机制相同，技能名称、说明、冷却和数值保持不变。
- 使用游戏原图中的金色立体星星，统一完整资料、选人信息栏和学生卡片的星级显示，保留真实星级及灰色未获得星位。

## 模型修复

- 修复玲纱（Reisa）嘴部缺失或显示白块的问题，保留原有眼睛、眉毛与动作。
- 修复优香（睡衣）胜利演出中木桶、佩洛洛及部分玩具剑缺失，并调整取景，避免道具被底边裁掉。
- 保留 Pick Up 互动、道具收起和顺滑动作切换，不修改原始 GLB 文件。

## 体验与兼容

- 完整资料支持中文、English、日本語、日夜主题及移动端；切换语言时保留当前页签与所选技能。
- 保留键盘页签操作、关闭后焦点返回和减少动态效果支持。
- 技能图片加载失败时使用备用图标，高对比模式保留可辨认的图形与文字。
- 补充技能映射、原图校验、三语界面及 HTTP 资源加载回归检查；同步更新 README、来源说明与维护流程。

## 使用说明

- 3D 模型和记忆大厅仍需通过 HTTP 服务打开；Windows 可双击项目中的 `start-preview.cmd`。直接打开 HTML 仍可查看立绘与资料。
- 本次不新增角色、不调整技能平衡；未逐帧验收所有模型动作与附件表现，遇到异常欢迎附角色名称、动作名称及截图反馈。
- 本项目为非官方同人资料站，游戏图像与相关素材版权归原权利方所有。
